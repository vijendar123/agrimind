# 🌱 AgriMind

AgriMind is a Streamlit agriculture advisory prototype built as a multi-agent workflow.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Agents

- Soil Agent
- Crop Agent
- Fertilizer Agent
- Risk Agent
- Final Recommendation Agent

The current version uses deterministic screening rules and does not claim to replace professional agronomic advice.
